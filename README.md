# Şehir Bul (Find the City)

A guessing game on the map of Turkey's provinces: the game names a province, and you find it on the map.
The correct province turns green, a wrong one turns red; you have 5 lives in total.

**🎮 Play: https://muhammedozkul.github.io/sehir-bul/**

## Running it on your computer

```sh
npm install
npm run dev
```

Written with Vite + TypeScript, no framework. On every push to the `main` branch,
GitHub Actions builds the game and publishes it to GitHub Pages.
